PowerPilot for Windows
======================

1. Move this folder somewhere permanent, e.g. C:\Users\<you>\Apps\PowerPilot.

2. Double-click PowerPilot.exe. The first time, it starts the background
   service (it then runs at every sign-in) and opens the dashboard in an
   Edge or Chrome app window. PowerPilot's battery icon in the notification
   area shows the UPS: click it for the dashboard, right-click for readings.

   Windows SmartScreen may warn that the app is unrecognised because it isn't
   code-signed: choose "More info", then "Run anyway".

The dashboard is also at http://127.0.0.1:8484 in any browser.

Uninstall: in a terminal, run  PowerPilot.exe uninstall
Settings and logs: %AppData%\PowerPilot
